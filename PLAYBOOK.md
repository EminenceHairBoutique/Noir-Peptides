## Heuristics (active)

- **H-001** [added cycle 1] In this category, structure implies intent more
  than copy does; audit variant ladders, blends, tools, and cross-sells before
  auditing sentences. — evidence (cycle 1): the only injection-consumable
  language in the tree was in *structural* places — a `lab_supply` type
  comment, a migration header, a schema doc — not in any rendered sentence;
  the regulator walk found them, the sentence scanner could not. — yield: 1
- **H-002** [added cycle 1] A visible empty column costs more trust than a
  hidden one; never render a trust field until it has ≥1 value. — evidence:
  Sept-11 T3 (CAS column hidden until populated) shipped and held; cycle 1
  found no regressions. — yield: 1 (Sept-11)
- **H-003** [added cycle 1] Anything the owner must do gets a command or a
  screen, or it will not get done. — evidence: the escalation item "enter
  `lab_lookup_code` per COA" has been open since Aug 28 with no screen; the
  admin COA form accepts neither `lab_id` nor `lab_lookup_code`, and no labs
  endpoint exists. Zero of 19 certificates have a lab link. — yield: 1
  (cycle 1 builds the screen)
- **H-004** [added cycle 1] Prices below the market floor read as fraud risk
  to sophisticated buyers; flag, don't fix. — evidence: none this cycle (no
  live pricing check possible from the sandbox); carried as stated. — yield: 0
- **H-005** [added cycle 1] If two sources of truth exist (static vs DB, UI vs
  server), write the diff test before the feature. — evidence: `tier1Catalog`
  → `0009` seed is regenerated by a script with no test that the committed
  seed matches the catalog; cycle 1 adds it. Also: any copy change to catalog
  data is NOT free — the seed uses `on conflict do update`, so the DB only
  follows if the seed is re-run. — yield: 1
- **H-006** [added cycle 1] The compliance scanner flags negative statements
  ("not for human consumption", "we do not provide dosing"). A corpus gate
  must therefore be an *exact* expected-findings allowlist, reviewed on every
  copy change — never a negation heuristic, never a whole-file exemption.
  — evidence: 10 of the 11 corpus entries the scanner flagged in cycle 1 are
  negations; the 11th ("treat findings as…") was the verb "regard". — yield: 1
- **H-007** [added cycle 1] A prompt's CONTEXT block goes stale between
  cycles. RECON must diff every numeric or state claim against a command
  output before planning, and the log must list the corrections. — evidence:
  cycle 1's CONTEXT was wrong on HEAD, audit count, suite count, sitemap size,
  category count, canonical host, and the entire §5 backlog (already merged).
  — yield: 1 (the corrected plan)
